

Для создания новой версии анкеты:

Пользователь заходит в карточку созданной анкеты;
Пользователь нажимает "Создать новую версию текущей анкеты"
Открывается форма создания новой анкеты со следующими параметрами:
Блок "Основная информация" наследуется от родительской (см. детализацию ниже);
Блок "Опросник" полностью наследуется от родительской;
Блок "Итоги расчета" перерассчитывается на текущих показателях средних и коэффициентах;
Предзаполняется поле "Родительская анкета";
Выводится информационное сообщение с информацией о том, что он в процессе редактирования анкеты;
Пользователь вносит изменения согласно стандартной логике и сохраняет анкету:
Созданной анкете присваивается статус "Активная"
У старой анкеты со статусом "Активная" с тем же идентификатором статус меняется на "Архив"

Для создание новой анкеты на базе текущей (клон):
Пользователь заходит в карточку созданной анкеты;
Пользователь нажимает "Использовать анкету как шаблон";
Открывается форма создания новой анкеты со следующими параметрами:
Блок "Основная информация" остается пустым;
Блок "Опросник" полностью наследуется от родительской;
Блок "Итоги расчета" перерассчитывается на текущих показателях средних и коэффициентах;
Предзаполняется атрибут "Идентификатор анкеты" ;
Поле "Родительская анкета" пустой.
Выводится информационное сообщение с информацией о том, что анкета создается на базе шаблона.
Пользователь вносит изменения согласно стандартной логике и сохраняет анкету:
Созданной анкете присваивается статус "Активная"


Общие требования:
Использовать для создания новой анкеты (в качестве шаблона или для создания новой версии) можно любую анкету, в том числе архивную.
При создании новой анкеты на базе текущей у пользователя должен быть выбор:
Создать новую анкету на базе шаблона;
Создать новую версию анкеты.


Прочее:


Для серии анкет с единым идентификатором серии может быть только 1 активная анкета.

При создании новой версии анкеты на базе текущей прошлой анкете со статусом "Активная" (с тем же числовым идентификатором) присваивается статус "Архив" (Имеется ввиду что прошлой анкете на базе которой создается новая версия анкеты, присваивается статус "Архивная", а вновь созданной статус "Активная")

Требования к атрибутивному составу при новой версии (UI):

Название анкеты - Наследуется
RFD - Наследуется
Стрим-исполнитель - Наследуется
Департамент Заказчика - Наследуется
Фио заказчика - Наследуется
Комментарий - Наследуется
Статус анкеты - Устанавливается на "Активная" после сохранения новой версии
Дата создания - Генерируется в момент сохранения новой версии
Родительская анкета - Предзаполняется идентификатором родительской анкеты (идентификатор должен содержать ссылку на родительскую анкету)(На счет ссылки не совсем понятно. Напиши пример)
Идентификатор - Сохраняется в момент сохранения анкеты, идентификатор серии наследуется, версия N+1 от последней версии в серии
Автор анкеты - Заполняется после сохранения анкеты
Все пункты опросника наследуются

Требования к атрибутивному составу при клонирования шаблона (UI):
Название анкеты - Не наследуется
RFD - Не наследуется
Стрим-исполнитель - Не наследуется
Департамент Заказчика - Не наследуется
Фио заказчика - Не наследуется
Комментарий - Не наследуется
Статус анкеты - Устанавливается на "Активная" после сохранения новой версии
Дата создания - Генерируется в момент сохранения анкеты
Родительская анкета - Остается пустым
Идентификатор - Сохраняется в момент сохранения анкеты, идентификатор серии уникальный, версия 1
Автор анкеты - Заполняется после сохранения анкеты
Все пункты опросника наследуются
