# Монорепозиторий на базе Turborepo

Этот проект представляет собой монорепозиторий, созданный с использованием [Turborepo](https://turbo.build/). Он включает в себя React-приложение, NestJS-сервер, и общие пакеты, все написанные на TypeScript.

---
Внимание! Отключите локально в вашем workspace все линтеры и фоматеры кроме Biome
Внимание! Добавьте переменную окружения APP_NAME в .env в корне проекта. APP_NAME=smartAnketa
---

## Структура проекта

- **`apps/`**: Содержит основные приложения
  - **`react-client/`**: Клиентское приложение на React и Vite
  - **`nestjs-server/`**: Серверное приложение на NestJS
- **`packages/`**: Содержит общие пакеты
  - **`core-lib/`**: Основная библиотека с общими компонентами (ПРИМЕР)
  - **`from-node-modules-example-lib/`**: Пример импорта библиотеки из node_modules, для обхода сб или форка

## Особенности проекта

### React клиент
- Визуализация и редактирование JSON в виде диаграмм
- Поддержка импорта/экспорта JSON файлов
- Редактор кода на базе Monaco Editor
- Возможность переключения между темной и светлой темами
- Построение диаграмм с использованием ReactFlow

### NestJS сервер
- Реализован на современном фреймворке NestJS
- Поддержка Fastify и Express
- Готовая инфраструктура для тестирования

## Скрипты

### Основные команды:

- **`npm run dev:fullstack`**: Запускает все приложения в режиме разработки параллельно
- **`npm run dev:ui`**: Запускает только React-клиент
- **`npm run dev:server:nest`**: Запускает только NestJS-сервер
- **`npm run build`**: Собирает все приложения
- **`npm run biome`**: Проверяет код с помощью Biome
- **`npm run biome:fix`**: Исправляет ошибки форматирования автоматически

### Команды для React клиента:

- **`npm run dev`**: Запускает Vite в режиме разработки
- **`npm run build`**: Собирает приложение для продакшена
- **`npm run biome:fix`**: Исправляет ошибки форматирования в директории ./src

### Команды для NestJS сервера:

- **`npm run dev`**: Запускает сервер с отслеживанием изменений
- **`npm run build`**: Собирает приложение
- **`npm run start`**: Запускает собранное приложение
- **`npm run test`**: Запускает тесты

## Зависимости

### Основные технологии

- **React 19**: Современная версия фреймворка React
- **Vite**: Быстрый инструмент сборки
- **NestJS 11**: Современный фреймворк для Node.js
- **TypeScript**: Строгая типизация для JavaScript
- **Turborepo**: Управление монорепозиторием
- **Zustand**: Менеджер состояний для React
- **ReactFlow**: Библиотека для визуализации графов
- **MUI**: Material UI компоненты

### Инструменты разработки

- **Biome**: Линтер и форматтер
- **Husky**: Git-хуки
- **Jest**: Тестирование
- **Commitlint**: Проверка коммитов
