
Порядок работы с анкетами в части фиксации оценок для отправки данных вовне (ОКСИ).
Версии анкеты. Каждая анкета имеет 1 и более версий. В каждый момент времени активна только 1 версия.
Готовность блоков. Представители стримов, участвующих в оценке инициативы, по факту завершения ввода данных завершают свой раздел — статус блока переходит в «Заполнено». Признак сбрасывается при изменении состава работ (типовых или нетиповых) в блоке.
Руководитель программ ДАДМ:
Фиксирует оценку (активную версию анкеты) на конкретный момент времени для отправки данных в ОКСИ, независимо от степени готовности данных. Для этого нажимает «Утвердить оценку по анкете» в форме анкеты либо в списке анкет (с возможностью выбрать одну или несколько анкет чекбоксами), переводя их в статус «Утверждена».
После фиксации версия заблокирована для заполнения всеми ролями. Внести изменения можно только созданием новой версии.
Создание новой версии (корректировка). Роль с правом создания с утверждённой анкеты нажимает «Создать новую версию». Система создаёт новую версию: тот же ID, версия +1, данные копируются полностью, статусы блоков сбрасываются на «Создано». Новая версия становится активной и редактируемой; утверждённая версия остаётся неизменной как исторический срез.
Создание копии (похожая инициатива). Роль с правом создания нажимает «Создать копию» (доступно всегда, для анкеты в любом статусе; Представитель стрима — только немодельные анкеты). Система создаёт новую анкету с новым ID (Версия = 1): заполненные поля переносятся, статусы блоков → «Создано». Дальше — работа как с самостоятельной анкетой.

Режим «Актуальные»: показывает последнюю актуальную версию анкеты (утверждённую или неутверждённую). Если после фиксации новой версии не создавалось — отображается зафиксированная версия, иначе — текущая рабочая.
Режим «Утверждённые» (последние зафиксированные): выводит строго последние зафиксированные версии анкет.

3. Добавить статус «Утверждена» в статусную модель анкеты.

комментарий

1. Сценарий: Менеджер программы ДАДМ — Утверждение анкеты
- Роль: Менеджер программы ДАДМ.
- Контекст: Сотрудник с данной ролью не заполняет анкету. Его задача — зафиксировать «срез» расчётов по инициативе на определённую дату и передать их дальше в систему ОКСИ, независимо от степени готовности данных.

Основной поток:
 1. Менеджер заходит в реестр анкет.
 2. Видит анкеты в любом статусе (может быть заполнена только часть разделов).
 3а. Выбирает чекбоксами одну или несколько анкет в списке анкет.
3b. Переходит в анкету и видит кнопку «утвердить анкету»
 4. Нажимает кнопку «Утвердить анкету» в списке анкет. 
 5. Система переводит выбранные версии анкет в статус «Утверждена».
 6. Менеджер выгружает данные анкеты в Excel для передачи в системы бюджетирования / проектного планирования.

Бизнес правило: Редактирование утверждённой версии анкеты невозможно ни для одной из ролей. Единственный способ внести изменения — создать новую версию (см. сценарий 1).

2. Сценарий: Исполнитель (роли с правом создания анкеты) — Создание версии для корректировки
- Роль: Исполнитель (роли с правом создания анкеты).
- Предусловие: Анкета находится в статусе «Утверждена» ИЛИ в статусе «Завершено заполнение».

Основной поток:
1. Исполнитель открывает анкету, видит активную кнопку «Создать новую версию».
2. Нажимает её. Система создает новую версию, полностью копируя данные за исключением статусов заполнения разделов (сбрасываются на «создано»). ID анкеты остается тем же, версия меняется на последующую.
3. Исполнитель вносит изменения в нужные разделы.
5. После завершения правок исполнитель снова переводит свои разделы в статус «Завершено заполнение».
6. Менеджер программы ДАДМ может снова утвердить уже новую версию на любом этапе работы с новой версией анкеты.

3. Сценарий: Исполнитель — Создание копии для похожей инициативы

Роль: Исполнитель (роли с правом создания анкеты) 
Предусловие: В системе есть анкета, которую можно взять за основу.
Основной поток:
1. Исполнитель открывает существующую анкету в любом статусе.
2. Нажимает кнопку «Создать копию» (доступна всегда).
3. Система создает новую анкету с новым ID (Версия=1). Все заполненные поля переносятся, статусы блоков меняются на «Создано».
4. Исполнитель работает с копией как с новой анкетой: меняет существующую информацию, заполняет оставшееся и завершает разделы.
